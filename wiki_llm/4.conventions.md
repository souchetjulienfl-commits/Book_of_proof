# Conventions du LLM Wiki

Ce document régit le fonctionnement, la structure et les règles de mise à jour du Wiki maintenu par l'IA.

---

## 1. Structure du Dépôt

- `raw/` : Sources brutes immutables (PDF, Markdown, transcriptions, HTML). Ne jamais modifier le contenu de ce dossier.
- `wiki/` : Base de connaissances vivante gérée par le LLM.
  - `wiki/index.md` : Catalogue orienté contenu avec résumés d'une ligne pour chaque page.
  - `wiki/log.md` : Journal chronologique des opérations (ingestions, requêtes, nettoyages).
  - `wiki/sources/` : Fiches synthétiques associées à chaque fichier brut de `raw/`.
  - `wiki/entities/` : Fiches sur les outils, personnes, frameworks, systèmes (ex: Rowboat, Ollama, Claude).
  - `wiki/concepts/` : Définitions et explications des idées clés (ex: Couche 2, Verifier Loop, RAG vs Wiki).
  - `wiki/analyses/` : Synthèses croisées, études comparatives et réflexions approfondies.

---

## 2. Workflows Standardisés

### A. Workflow d'Ingestion (`Ingest`)
Lorsqu'un nouveau document est ajouté dans `raw/` :
1. Lire et analyser le document brut.
2. Créer une fiche source dans `wiki/sources/{nom_source}.md`.
3. Identifier les entités et concepts clés présentés dans le document.
4. Créer ou mettre à jour les fiches correspondantes dans `wiki/entities/` et `wiki/concepts/`.
5. Ajouter des liens wiki réciproques (ex: `[[karpathy_method]]`).
6. Mettre à jour `wiki/index.md` avec une description courte de chaque nouvelle page.
7. Ajouter une entrée datée dans `wiki/log.md`.

### B. Workflow de Requête (`Query`)
Lorsqu'une question est posée au système :
1. Consulter `wiki/index.md` pour repérer les pages pertinentes.
2. Lire les pages wiki correspondantes (et non les documents bruts, sauf besoin d'extraire une citation exacte).
3. Formuler la réponse en citant les fiches du wiki.
4. Si la requête révèle une lacune ou nécessite une nouvelle synthèse croisée, créer un fichier dans `wiki/analyses/`.

### C. Workflow de Cohérence (`Lint`)
Périodiquement ou lors d'ajouts majeurs :
1. Vérifier les liens orphelins ou brisés (`[[lien]]`).
2. Fusionner les concepts similaires ou redondants.
3. S'assurer que chaque page du wiki est référencée dans `wiki/index.md`.
